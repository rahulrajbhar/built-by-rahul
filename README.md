# Built by Rahul — AI-Assisted Web Development

A clean, modern React web application for **Built by Rahul**, specializing in high-speed, requirements-first website design and development for small businesses and solo founders.

Built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features

- **Hero & Interactive Execution Pipeline**: Visual timeline representing the 4-phase agile delivery cycle (v0.1 Brief, v0.2 Draft, v0.3 Refine, v1.0 Ship) with an interactive inspector.
- **01 — Process**: Transparent four-stage client onboarding and delivery breakdown.
- **02 — Why AI-Assisted**: Business rationale pairing 13+ years of enterprise Business Analyst rigor with modern AI velocity.
- **03 — What I Build**: Core service cards with instant category filtering (Landing Pages, Small Business Sites, Portfolio Sites, Website Refresh).
- **04 — Interactive Sample Work**:
  - Filterable live showcases with full ARIA accessibility (`role="group"`, `aria-pressed`, `aria-live="polite"`).
  - In-app interactive Device Preview Modal with responsive viewport toggle (Desktop, Tablet, Mobile).
  - Standalone live demo links for all showcase builds (Aura Wellness, Vanguard Design & Build, Devon Vance CPO, Heritage Auto).
- **05 — Simple Upfront Pricing**: Fixed-scope tiers (Starter, Standard, Custom) with one-click package preselection into the inquiry form.
- **06 — About Rahul**: Senior Business Analyst background, delivery credentials, and personal accountability guarantee.
- **07 — FAQ**: Expandable questions and answers addressing AI quality, delivery speed, and post-launch support.
- **08 — Interactive Scope & Inquiry Form**: Fully accessible lead capture with real-time email mailto generator, WhatsApp deep link, and clipboard copy.

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build
```
